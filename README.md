# Seriesly

Film ve dizi takip sistemi - izlediklerinizi, izlemek istediklerinizi ve tamamladıklarınızı organize edin.

## Özellikler

- **İçerik Yönetimi**: Film ve dizi ekleme, düzenleme ve silme
- **Kategorilendirme**: Tür, kategori ve izleme durumuna göre filtreleme
- **Sıralama**: İsme, yıla, puana veya eklenme tarihine göre sıralama
- **Arama**: Film/dizi adı, yönetmen veya orijinal başlık üzerinden arama
- **İstatistikler**: Toplam içerik, tamamlananlar, izlenenler ve ortalama puan görüntüleme
- **LocalStorage**: Veriler tarayıcıda saklanır, kayıt gerekmez

## Teknolojiler

- **React**: UI kütüphanesi
- **Vite**: Hızlı geliştirme sunucusu ve build aracı
- **Tailwind CSS**: Stil framework
- **LocalStorage**: Veri saklama

## Kurulum

```bash
npm install
```

## Çalıştırma


## Build
